## المميزات الرئيسية (Key Features)

- **منظومة الأدوار الخمسة المتكاملة (Multi-Role Architecture)**:
  - **المرضى (Patients)**: حجز استشارات طبية فورية، اختيار الأسنان عبر مجسم ثلاثي الأبعاد، تصفح الأطباء المعتمدين، حجز مواعيد العيادة، ومحادثة مباشرة مع الطبيب.
  - **الأطباء المعتمدون (Doctors)**: لوحة تحكم ذكية، فرز التراياج (قيد الانتظار / تم التشخيص)، فحص الحالات والأشعة، إرسال التشخيص، وإدارة الخدمات والأسعار والمحفظة.
  - **الأطباء قيد الاعتماد (Pending Doctors)**: شاشة متابعة حالة تدقيق ترخيص مزاولة المهنة ورقم القيد بالنقابة، مع زر للتواصل المباشر مع الدعم الفني وتحديث لحظي للحالة.
  - **السكرتارية والاستقبال (Clinic Assistants)**: واجهة مخصصة لإدارة طابور المواعيد اليومي، تأكيد الحضور، إتمام الكشف، والتواصل مع المرضى دون صلاحية تعديل التشخيص الطبي.
  - **المدير العام (Super Admin)**: لوحة تحكم مركزية لمتابعة مؤشرات أداء المنصة، فحص استمارات الأطباء كاملة وتدقيق التراخيص، التواصل مع الطبيب عبر واتساب أو الهاتف، واعتماد الحسابات أو رفضها مع توضيح السبب.

- **مجسم الأسنان والفك التشريحي (Interactive Dental Chart)**:
  - عرض مجسم الفك التشريحي ثلاثي الأبعاد بدقة متناهية ودون أي قص عرضي.
  - ميزة التكبير لشاشة كاملة لفحص كافة الأسنان وترقيمها (1 إلى 32).
  - تحديد مواضع الألم بدقة وربطها بالاستشارة الطبية.

- **دليل الأطباء (Doctor Directory)**: استعراض الأطباء المعتمدين، التخصصات، التقييمات، والأسعار مع فلاتر وبحث فوري.
- **بروفايل الطبيب التفاعلي**: صفحة متكاملة لكل طبيب تشمل معرض الحالات (Before & After Slider)، الأسعار، ومواعيد العمل.
- **استشارات فورية عن بعد (Online Triage & Consultations)**: إمكانية إرفاق صور الأسنان والأشعة وتحديد مواضع الألم، مع محادثة مباشرة مع الطبيب.
- **منع الحجز المزدوج (Double Booking Prevention)**: نظام حجز متطور ومؤمن بقواعد بيانات Supabase يمنع تضارب المواعيد.
- **تنبيهات فورية ولحظية (Real-time Subscriptions)**: استماع لحظي للرسائل والاستشارات الجديدة عبر قنوات Supabase Realtime WebSockets.

## التقنيات المستخدمة (Tech Stack)

- **Frontend**: React Native (v0.76), Expo (SDK 52), TypeScript, React Navigation
- **Backend & Database**: Supabase (PostgreSQL with RLS, Realtime Channels, Storage Buckets)
- **State Management**: React Context API + AsyncStorage
