# خطة التطوير والتحديثات الشاملة - منصة أسنانجي (Asnanji v1.2.0)
**تاريخ الخطة:** 13 أكتوبر 2026  
**الهدف:** تصحيح تجربة المستخدم (UX)، فصل حساب الإدارة بالكامل بلوحة تحكم وتحليلات متقدمة، إزالة البيانات والأرقام التجريبية، وتصحيح مسار تسجيل الدخول وإنشاء الحسابات.

## 📌 1. ملخص المشاكل والمتطلبات المرصودة

1. **تضارب شاشة "حسابي" (ProfileScreen):**
   - عدم وجود زر صريح لـ "إنشاء حساب جديد" للزائر.
   - وجود زر وحيد بالأسفل موجه فقط للأطباء، مما يربك المستخدم العادي.
   - عدم وجود خيار لتسجيل الخروج لأي مستخدم مريض أو مسؤول.

2. **تجمد الشاشة بعد تسجيل الدخول (AuthScreen Freeze):**
   - عند نجاح تسجيل دخول الأدمن أو أي مستخدم، لا يتم إغلاق شاشة الدخول تلقائياً أو التوجيه للواجهة المطلوبة، مما يجبر المستخدم على قفل التطبيق وإعادة فتحه.

3. **هوية حساب الأدمن (Super Admin Role):**
   - حساب الأدمن يتم توجيهه لواجهة طبيب الأسنان (`DoctorTabs`) وكأنه طبيب يمتلك عيادة خاصة، بينما المطلوب واجهة إدارية احترافية لمدير ومسؤول المنصة بالكامل.

4. **لوحة تحليلات وإحصائيات الأدمن (Admin Analytics & Usage Dashboard):**
   - بناء صفحة إحصائيات متكاملة تعرض عدد الأطباء والحسابات وتوزيعها، نشاط كل دكتور (استشارات، حجوزات، زيارات)، وتحليل استخدام المنصة والمحافظات.
   - مراجعة واعتماد طلبات الأطباء بنقرة زر واحدة.

5. **إزالة كافة الأمثلة والأرقام التجريبية (Purge All Mock / Dummy Data):**
   - إزالة أي حالات علاجية تجريبية (قبل/بعد) افتراضية.
   - إزالة الأرقام الوهمية (مثل 1500 مريض، 12 سنة خبرة، 385 تقييم، أرقام هواتف وهمية `0100 000 0000`).
   - ربط جميع الإحصائيات والأرقام بالبيانات الفعلية في قاعدة بيانات Supabase.

  - السبب البرمجي: كود `signInWithOAuth` كان يستلم الرابط `data.url` من Supabase دون استدعاء `Linking.openURL(data.url)`، وبالتالي لا يفتح المتصفح للمستخدم على الهاتف.
  - الحل: استدعاء `Linking.openURL` فوراً لفتح نافذة اختيار حساب Google، مع معالجة الـ Callback وحالة الرجوع بسلاسة.
- [ ] **إصلاح زر إنشاء الحساب (Sign Up Action & Auto-Redirect):**
  - السبب البرمجي: عند الضغط على "إنشاء الحساب الآن"، في حالة النجاح لا يقوم الكود بإغلاق الشاشة أو توجيه المستخدم، فتظل الشاشة متوقفة وكأن شيئاً لم يحدث!

    1. إظهار رسالة نجاح وتأكيد واضحة فور إنشاء الحساب: *"تم إنشاء حسابك بنجاح! مرحباً بك في أسنانجي 🎉"*.
    2. التوجيه التلقائي الفوري وإغلاق شاشة الـ Auth (`navigation.goBack()` أو Reset Navigation إلى الواجهة المناسبة).
    3. التعامل الذكي مع تسجيل الدخول المباشر بعد الإنشاء لضمان دخول المستخدم فوراً إلى حسابه الجديد.

### المرحلة الرابعة: إنشاء لوحة تحكم وتحليلات الإدارة (Admin Panel & Dashboard)
- [ ] **إنشاء المكون `AdminTabs` في `App.tsx`:**
  - توجيه الحسابات ذات الدور `role === 'admin'` إلى `AdminTabs` بدلاً من `DoctorTabs`.
- [ ] **إنشاء الشاشات الإدارية:**
  1. **شاشة لوحة تحليلات المنصة (`AdminDashboardScreen.tsx`):**
     - **بطاقات المؤشرات الرئيسية (KPIs):** إجمالي المستخدمين، عدد المرضى، عدد الأطباء المعتمدين، طلبات الاعتماد المعلقة، إجمالي الاستشارات، إجمالي المواعيد.
     - **توزيع الحسابات:** رسم توضيحي لنسب المسجلين (مرضى vs أطباء vs مساعدين).
     - **تحليل نشاط الأطباء (Doctor Activity Monitor):** جدول/قائمة لكل دكتور يوضح:
       - عدد الاستشارات التي استقبلها ونسبة الردود.
       - عدد الحجوزات والمواعيد.
       - عدد زيارات ملفه الشخصي (`doctorViews`).
       - التقييم وحالة قبول المرضى.
     - **التوزيع الجغرافي:** توزيع الأطباء والعيادات حسب المحافظات.
  2. **شاشة اعتماد وإدارة طلبات الأطباء (`AdminDoctorApplicationsScreen.tsx`):**
     - **استعراض تفاصيل الاستمارة بالكامل (Full Application Inspection Modal):**
       - حل المشكلة المرصودة: إمكانية النقر على أي طلب لفتح استمارة الطبيب بالكامل في نافذة تفصيلية أنيقة ومفصلة.
       - عرض: الاسم الكامل، التخصص، الدرجة العلمية (أخصائي/استشاري/أستاذ)، رقم القيد بالنقابة، عنوان العيادة، المحافظة، سعر الكشف، رقم الهاتف والبريد، وتاريخ التقديم.
       - إمكانية التواصل السريع مع الطبيب عبر الهاتف أو الواتساب مباشرة من داخل الاستمارة للتأكد من بياناته.
     - **اتخاذ القرار بنقرة واحدة:**
       - زر اعتماد فوري (Approve) ينشئ بروفايل الطبيب ويفعله بالسوق مباشرة مع إشعار نجاح.
       - زر رفض (Reject) مع إمكانية كتابة سبب الرفض لتوضيحه للطبيب.
  3. **شاشة ملف مدير المنصة (`AdminProfileScreen`):**
     - هوية المسؤول، فحص سيرفر Supabase وإصدارات التطبيق، وتسجيل الخروج.
